# 地球的公转与四季

一个单文件、零依赖的交互式天文演示。用 Canvas 逐像素渲染球面，演示地球自转、公转与四季成因。

## 看什么

- **昼夜晨昏线**：地球一半在阳光里、一半在阴影里，分界线固定朝向太阳
- **地轴倾角**：地轴始终保持 23.44° 倾角，公转过程中指向不变 —— 这就是四季的根源
- **太阳直射点**：在南北回归线之间往返，实时显示纬度与移动方向
- **昼长变化**：可调观测纬度，曲线展示全年昼长波动，极圈内可见极昼极夜

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击底部节气按钮 | 缓动跳转到春分 / 夏至 / 秋分 / 冬至 |
| 空格键 | 暂停 / 继续 |
| 拖动速度条 | 0.2× – 3× |
| 拖动纬度滑块 | 切换观测点，昼长曲线随之重算 |

## 数据校验

| 时点 | 太阳直射点 | 北纬 40° 昼长 |
| --- | --- | --- |
| 春分 | 赤道 0° | 12h02m |
| 夏至 | 北纬 23.44° | 14h51m |
| 冬至 | 南纬 23.44° | 9h09m |

## 文件

`index.html` —— 全部内容（HTML / CSS / JS / 贴图 base64）都在这一个文件里，无任何外部依赖，双击即可离线打开。

`.nojekyll` —— 告诉 GitHub Pages 跳过 Jekyll 处理，直接原样发布静态文件。
